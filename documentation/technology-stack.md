# Technology Stack

The stack below is taken from the existing project's package manifest and application structure. This document describes the app at a high level and intentionally contains no implementation source code.

| Technology | Role in the current project  ----------------  --------  |
|                     --- | ---                                         |
| React 19 | Frontend component rendering and UI structure              |
| TypeScript 5.8 | Frontend language and type checking                  |
| Vite 6 | Development server and production build tooling              |
| CSS | Dashboard layout, themes, responsive behavior, and presentation |

The project uses custom application state and URL hashes for its page navigation; React Router is not listed as a dependency. The showcase makes no claim of a backend, database, cloud platform, authentication system, or IoT transport being connected.
